# Pronto Pizza

Website for **Pronto Pizza**, a pizzeria and Italian restaurant in Porlezza (CO), on Lake Lugano.

🌐 Live: https://ristoranteppdafabio.it

## Run locally

This is a static website — no build step needed.

```bash
# from this folder
python3 -m http.server 8080
# then open http://localhost:8080
```

Or just open `index.html` in your browser.

## Pages

- `index.html` — home
- `menu.html` — menu
- `css/` — styles · `js/` — scripts (includes language switch) · `img/` — photos

## Tech

Plain HTML, CSS and JavaScript.
